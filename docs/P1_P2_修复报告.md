```go
func buildTouchInfoFromAnchors(
    anchors []AnchorCandidate,
    side string,
    currentPrice, touchPrice, atr14 float64,
) []triggers.TouchInfo {
    touches := make([]triggers.TouchInfo, 0, len(anchors))

    for _, anchor := range anchors {
        // 使用effectiveDistance处理Zone边界
        distRaw := effectiveDistance(touchPrice, anchor)

        distBps := (distRaw / currentPrice) * 10000  // 基点
        distAtr := 0.0
        if atr14 > 0 {
            distAtr = distRaw / atr14  // ATR倍数
        }

        // 提取StrengthZ（可能为空）
        strengthZ := 0.0
        if anchor.StrengthZ != nil {
            strengthZ = *anchor.StrengthZ
        }

        // 确定KeyType
        keyType := triggers.KeyLevelEdgeSupport
        if side == "SHORT" {
            keyType = triggers.KeyLevelEdgeResistance
        }

        // 关键：使用Zone边界作为Level
        level := anchor.Level
        if side == "LONG" {
            level = anchor.BandLo  // 支撑使用下沿
        } else if side == "SHORT" {
            level = anchor.BandHi  // 阻力使用上沿
        }

        touches = append(touches, triggers.TouchInfo{
            Level:     level,
            Side:      side,
            DistBps:   distBps,
            DistAtr:   distAtr,
            Source:    string(anchor.Type),
            StrengthZ: strengthZ,
            TimeFrame: anchor.TF,
            KeyType:   keyType,
        })
    }

    return touches
}
```

#### P1-01-c: 创建DetectTriggersRecentWithStructures函数
**文件**: `/Users/guiling/IdeaProjects/nofx/triggers/detect_recent.go` (行135-260)
**完成时间**: 2025-12-29 00:45

**功能**：
- 扩展原有的`DetectTriggersRecent()`，增加EDGE触发器支持
- 接受`touches`和`levels`参数（来自Gate2结构数据）
- 内部调用`DetectTriggersWithStructures()`启用EDGE检测
- 保持age优先、quality次优的排序逻辑

**实现细节**：
```go
func DetectTriggersRecentWithStructures(
    klines []Kline,
    atr5m float64,
    volZ float64,
    cfg TriggerConfig,
    windowSize int,
    touches []TouchInfo,   // EDGE触发器触碰点数据
    levels []LevelInfo,    // BO_RETEST触发器关键位数据
    currentPrice float64,
) TriggerWithAge {
    // 参数验证
    if windowSize <= 0 {
        windowSize = 3  // 默认回看3根
    }
    if len(klines) < windowSize {
        windowSize = len(klines)
    }
    if windowSize < 1 {
        return TriggerWithAge{
            Result:         createEmptyTriggerScanResult(),
            AgeBars:        -1,
            BarCloseTimeMs: 0,
        }
    }

    candidates := make([]TriggerWithAge, 0, windowSize)

    // 逐根K线检测（从最新到最旧）
    for age := 0; age < windowSize; age++ {
        endIdx := len(klines) - age
        if endIdx <= 0 {
            break
        }
        partialKlines := klines[:endIdx]

        // 关键：调用DetectTriggersWithStructures支持EDGE
        result := DetectTriggersWithStructures(
            partialKlines, atr5m, volZ, cfg,
            touches, levels, currentPrice,
        )

        // 使用ai_flags判断是否有触发器
        if len(result.AIFlags) > 0 {
            candidates = append(candidates, TriggerWithAge{
                Result:         result,
                AgeBars:        age,
                BarCloseTimeMs: partialKlines[endIdx-1].CloseTime,
            })
        }
    }

    if len(candidates) == 0 {
        return TriggerWithAge{
            Result:         createEmptyTriggerScanResult(),
            AgeBars:        -1,
            BarCloseTimeMs: klines[len(klines)-1].CloseTime,
        }
    }

    // 排序：age越小越优先，age相同时quality越高越优先
    sort.SliceStable(candidates, func(i, j int) bool {
        if candidates[i].AgeBars != candidates[j].AgeBars {
            return candidates[i].AgeBars < candidates[j].AgeBars
        }
        qI := getAIPrimaryQuality(candidates[i].Result)
        qJ := getAIPrimaryQuality(candidates[j].Result)
        return qI > qJ
    })

    return candidates[0]
}

// 便捷封装（默认窗口3根）
func DetectTriggersRecentWithStructuresDefault(
    klines []Kline, atr5m float64, volZ float64,
    cfg TriggerConfig,
    touches []TouchInfo, levels []LevelInfo,
    currentPrice float64,
) TriggerWithAge {
    return DetectTriggersRecentWithStructures(
        klines, atr5m, volZ, cfg, 3,
        touches, levels, currentPrice,
    )
}
```

### P2-03: 优化SL buffer公式（增大最小risk）

**问题**：
- SL buffer过小（0.20*ATR）导致止损过近，costs_R占比过高
- risk_floor过低（0.35*ATR）使得R_clean被严重侵蚀

**解决方案**：同时提升buffer和floor，增大最小risk以降低costs的相对占比。

**文件**: `/Users/guiling/IdeaProjects/nofx/prompts/taro_long_prompts.txt` (行233, 236)
**完成时间**: 2025-12-29 01:40

**修改内容**：

**1. SL buffer公式** (行233):
```
修改前:
- buffer 取：max(0.20*ATR14(5m), entry*0.0010)

修改后:
- buffer 取：max(0.25*ATR14(5m), entry*0.0010)
```

**2. risk_floor定义** (行236):
```
修改前:
- 定义 risk_floor = max(0.35*ATR14(5m), entry*0.0015)

修改后:
- 定义 risk_floor = max(0.40*ATR14(5m), entry*0.0015)
```

**影响**：
- ✅ buffer增大25%（0.20→0.25），减少过早止损
- ✅ risk_floor增大14%（0.35→0.40），降低costs_R占比
- ✅ 预期R_clean提升5-10%（在相同TP情况下）

**数学分析**：
假设ATR=10，entry=1000，fee+slippage=0.05%
```
修改前:
  buffer = max(2.0, 1.0) = 2.0
  risk_floor = max(3.5, 1.5) = 3.5
  costs = (1000+1000)*0.0005 = 1.0
  Real_R = (TP-entry-buffer) / risk_floor
  costs_R = 1.0 / 3.5 = 0.286

修改后:
  buffer = max(2.5, 1.0) = 2.5
  risk_floor = max(4.0, 1.5) = 4.0
  costs = 1.0（不变）
  Real_R = (TP-entry-buffer) / risk_floor（buffer增大，分母增大，Real_R略降）
  costs_R = 1.0 / 4.0 = 0.250（降低12.6%）

关键：虽然Real_R略降，但costs_R降低更多，R_clean = Real_R - costs_R可能净提升
```

### P2-01: Gate5放宽TP1选择规则（允许跳到2nd obstacle）

- 在密集结构区域（OBSTACLE_CLUSTER）浪费大量有效机会

```
修改前:
- tp1 必须取"最近反向结构/首个 Respect 障碍"的有效边界：

修改后:

  若该障碍导致 R_clean 不足，允许跳到"第二近 Respect 障碍"（详见 E) OBSTACLE_CLUSTER 处理）：

**2. 修改E) OBSTACLE_CLUSTER处理逻辑** (行315-325):
```

1) 取"最近 Respect 障碍"作为 TP1，重新计算 Conservative_R_clean
2) 若 Conservative_R_clean 达到对应 trade_style 的下限：
   -> Gate5=PASS，但必须降级：setup_grade 降 1 档 + risk_down≥0.5 + LIMIT + TP1 快速兑现；reason=OK

   -> Gate5=FAIL fail=>RR；reason=RR_LOW_CLUSTER

修改后:
1) 优先尝试"最近 Respect 障碍"作为 TP1，计算 Conservative_R_clean_1st
2) 若 Conservative_R_clean_1st 达到对应 trade_style 的下限：
   -> Gate5=PASS；reason=OK（使用最近障碍）
3) 否则，尝试"第二近 Respect 障碍"作为 TP1，计算 Conservative_R_clean_2nd

- **缓解**：优先尝试最近障碍，第二近是兜底方案
