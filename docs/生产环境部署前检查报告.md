## ⚠️ 发现的严重问题

### 🔴 问题1: 弱信号过滤逻辑有缺陷

**位置**: `internal/direction/compute.go:215-217`

```go
if abs(structDir) < 0.3 && abs(ofDir) < 0.3 {
    flags = append(flags, "WEAK_SIGNAL_FILTERED")
    side = SideNeutral
}
```

**问题**:
1. **逻辑错误**: 这段代码在`side`已经被赋值为`SideNeutral`之后才执行
2. **无效过滤**: 如果`delta >= ThetaNeutral`且`conf >= MinConf`，`side`会被设置为LONG/SHORT，然后这个过滤逻辑不会改变它
3. **标记误导**: 即使添加了`WEAK_SIGNAL_FILTERED`标记，但`side`可能已经是LONG/SHORT

**正确逻辑应该是**:
```go
// 先检查弱信号
if abs(structDir) < 0.3 && abs(ofDir) < 0.3 {
    flags = append(flags, "WEAK_SIGNAL_FILTERED")
    side = SideNeutral
} else {
    // 只有非弱信号才进行方向裁决
    if abs(delta) >= cfg.ThetaNeutral && conf >= cfg.MinConf {
        if delta > 0 {
            side = SideLong
        } else {
            side = SideShort
        }
    }
}
```

**影响**:
- ❌ 弱信号可能仍然通过
- ❌ 测试中看起来有效是因为测试案例的delta本身就小于ThetaNeutral
- ❌ 真实环境中，如果delta >= 0.20但structDir和ofDir都<0.3，仍会开仓

**风险等级**: 🔴 高风险 - 可能导致弱信号交易

---

side := SideNeutral

// 🔥 修复：过滤弱信号，避免在震荡市中频繁亏损
// 当结构和订单流都是弱信号时，强制NEUTRAL
if abs(structDir) < 0.3 && abs(ofDir) < 0.3 {
    flags = append(flags, "WEAK_SIGNAL_FILTERED")

    // 只有非弱信号才进行方向裁决
    if abs(delta) >= cfg.ThetaNeutral && conf >= cfg.MinConf {
