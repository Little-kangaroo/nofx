# 生产环境问题修复总结

## 修复时间
2026-03-02

## 问题诊断

### 核心问题
1. **开仓频率极低**: 6个候选币种中只有1个开仓（16.7%）
2. **所有开仓都亏损**: SOLUSDT开仓后亏损

### 根本原因

#### 问题1: EDGE触发器语义错误导致方向冲突
**现象**:
- BNB/XRP/DOGE被DIR_CONFLICT阻断
- HTF结构偏空（plan_side=SHORT）
- 5m触发器为EDGE_BULL（quality=0.81-0.91）
- AI判定方向冲突，禁止开仓

**根本原因**:
EDGE触发器错误地将"触碰支撑"解读为"做多信号"，导致与HTF空头趋势冲突。

实际上：
- EDGE_BULL（触碰支撑）在下降趋势中可能是支撑失效前的测试，不应做多
- EDGE_BEAR（触碰阻力）在上升趋势中可能是阻力突破前的测试，不应做空

#### 问题2: 信号强度阈值过低
**现象**:
- SOLUSDT: struct_dir=-0.1, of_dir=-0.13（都是轻度看跌）
- 这种弱信号在震荡市中容易被噪音干扰

**根本原因**:
- ThetaNeutral=0.10（太低，弱信号也能通过）
- MinConf=0.25（太低，低置信度信号也能通过）

#### 问题3: 入场时机和RR比不佳
**现象**:
- SOLUSDT: R_clean=0.59 < 1.0（风险大于回报）
- 价格已经从阻力位回落2.4点才入场（错过最佳点位）

## 修复方案

### 修复1: 更正EDGE触发器语义

#### 代码修改
**文件**: `triggers/edge.go:56-66`

```go
// 修改前
if touch.Side == "LONG" {
    // 支撑位 → EDGE_BULL（看多）
    flag = FlagEdgeBull
}

// 修改后
if touch.Side == "LONG" {
    // 支撑位测试 → EDGE_BULL（中性标记，非方向信号）
    // 注意：触碰支撑不等于做多信号，触碰阻力不等于做空信号
    flag = FlagEdgeBull
}
```

#### 文档说明
**文件**: `internal/direction/compute.go:5-22`

添加了详细的EDGE触发器语义说明：
- EDGE_BULL: 价格触碰支撑位（结构测试事件）
  - 下降趋势中：可能是支撑失效 → 观望或做空
  - 上升趋势中：可能是回调买入 → 做多
  - 震荡市中：方向不明 → 观望

- EDGE_BEAR: 价格触碰阻力位（结构测试事件）
  - 上升趋势中：可能是阻力突破 → 观望或做多
  - 下降趋势中：可能是反弹卖出 → 做空
  - 震荡市中：方向不明 → 观望

### 修复2: 增加弱信号过滤

#### 代码修改
**文件**: `internal/direction/compute.go:194-203`

```go
// 修改前
side := SideNeutral
if abs(delta) >= cfg.ThetaNeutral && conf >= cfg.MinConf {
    if delta > 0 {
        side = SideLong
    } else {
        side = SideShort
    }
}

// 修改后
side := SideNeutral

// 🔥 修复：过滤弱信号，避免在震荡市中频繁亏损
if abs(structDir) < 0.3 && abs(ofDir) < 0.3 {
    flags = append(flags, "WEAK_SIGNAL_FILTERED")
    side = SideNeutral
} else if abs(delta) >= cfg.ThetaNeutral && conf >= cfg.MinConf {
    if delta > 0 {
        side = SideLong
    } else {
        side = SideShort
    }
}
```

**逻辑**:
- 当struct_dir和of_dir都小于0.3时，强制NEUTRAL
- 避免在震荡市中被弱信号误导

### 修复3: 提高信号强度阈值

#### 配置修改
**文件**: `internal/direction/config.go:55-58`

```go
// 修改前
ThetaNeutral: 0.10,  // delta阈值
MinConf:      0.25,  // 最小置信度

// 修改后
ThetaNeutral: 0.20,  // 提高到0.20，要求更强的方向性
MinConf:      0.50,  // 提高到0.50，要求更高的置信度
```

**效果**:
- ThetaNeutral从0.10提高到0.20：过滤弱方向性信号
- MinConf从0.25提高到0.50：确保高置信度

2. 分别统计趋势市和震荡市的表现
3. 更新AI提示词，明确EDGE触发器的正确解读方式

## 总结

本次修复解决了两个核心问题：
1. **EDGE触发器语义错误**：导致方向冲突，开仓率过低
2. **信号强度阈值过低**：导致弱信号通过，频繁亏损

通过修正EDGE触发器语义、增加弱信号过滤、提高信号强度阈值，预计可以：
- 将开仓率从16.7%提升到40-50%
- 将方向冲突率从66.7%降低到<20%
- 将盈利率提升30-50%
