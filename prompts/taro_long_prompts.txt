一、输入数据协议（Matrix Compressed Protocol - Schema V3.0）
——————————————————————————————————————
【严重警告】必须严格遵循以下索引(Index)与枚举(Enum)定义解码矩阵。以此协议为准，严禁猜测。

【全局索引】
- TF (Timeframe Index): 0=5m, 1=15m, 2=30m, 3=1h, 4=4h

1. ROOT STRUCTURE (全局):
   - { "s": Symbol, "p": Price, "t": Timestamp }
   - g: [Change1h%, Change4h%, Funding, LastPrice, OI]

2. BASIC INDICATORS "I" (基础指标):
   - Format: { "key": [TF0...TF4] }
   - Keys: atr, avg_v, e20, e50, e100, e200, e50s, e200s, macd, r7, r14, s20, s50, vol, vwap
   - ohlc (5m only): [Open, High, Low, Close, Volume] <-- 必须用于形态确认

3. ANALYSIS "A" (高级分析矩阵):

   ➤ FVG "G": [TF, Type, Upper, Lower, Strength, TouchCount, Quality, Status, Fresh, Rank, StrengthZ, TimeScore, VolRatio, WidthATR]
     * Type: 0=bullish(看涨/支撑), 1=bearish(看跌/阻力)  <--【核心对齐】
     * Quality: 0=low, 1=medium, 2=high
     * Status: 0=tested, 1=fresh

   ➤ FVG_META "G_M": [TF, ActiveGaps, GapType, NearestGap]
     * GapType: 0=bearish, 1=neutral, 2=bullish

   ➤ 供需区 "SD": [TF, Type, High, Low, Strength, Touches, Status, Fresh, Rank, StrengthZ, TimeScore, VolRatio, WidthATR]
     * Type: 0=demand(支撑), 1=supply(阻力)
     * Status: 0=tested, 1=fresh

   ➤ 供需区_META "SD_M": [TF, TotalZones, AvgStrength, DemandCount, SupplyCount]

   ➤ 支撑阻力 "SR": [TF, Price, Strength, HitCount, Type]
     * Type: 0=support, 1=resistance

   ➤ 支撑阻力_META "SR_M": [TF, ResistanceLines, SupportLines, TotalLines]

   ➤ VPVR "VP": [POC, VAH, VAL] (Row对应TF)

   ➤ 斐波纳契 "F": [0.236, 0.382, 0.500, 0.618, 0.786, 1.000, 1.272, 1.618, 2.618]
     * 数组索引固定对应上述比率，Row对应TF。

   ➤ 斐波纳契_META "F_M": [TF, ActiveRetracements, TrendDirection]
     * TrendDirection: 0=bearish, 1=neutral, 2=bullish

   ➤ 超级趋势 "ST": [TF, CurrentLine, Direction]
     * Direction: 1=bullish(多), 2=bearish(空) <--【核心对齐】

   ➤ 通道 "CH": [TF, ChannelDirection, ChannelWidth, CurrentPosition]
     * ChannelDirection: 0=bearish(降), 1=sideways(平), 2=bullish(升)

   ➤ 道氏理论 "DOW": [TF, SignalConfidence, TrendDirection, TrendStrength, STCurrentLine, STDirection, STLowerLine, STUpperLine]
     * TrendDirection: 0=bearish, 1=neutral, 2=bullish
     * STDirection: 1=up, 2=down

二、硬性过滤器 (Blood Rules - V8.9 Kernel)
——————————————————————————————————————
任何开仓(Open)操作前必须通过以下检查，否则 ACTION="wait"。

G1. 僵尸/吸筹判定 (Zombie Zone):
   - SD.Touches > 8 ⇒ 区域失效（流动性耗尽）。
   - SD.Touches > 5 AND VolRatio > 2.0 ⇒ 吸筹/出货模式（巨量不反弹），预期突破，禁止反转。

G2. 铁墙判定 (Iron Wall):
   - SR.Hits >= 10 OR Strength >= 0.9 ⇒ 视为铁墙。
   - 若 Entry 距离铁墙 < 1.0 R 且无法穿透 ⇒ ABORT。

G3. 震荡市过滤 (Chop Filter):
   - 定义 POC_chop_zone: `|Price - POC| <= 0.25 * ATR(15m)`
   - 若 Price 落在 POC_chop_zone 或 [VAL, VAH] 中部:
     * 禁止 BO_RETEST（假突破高危）。
     * 禁止 顺势追单。
     * 仅允许在 VAH/VAL 边界做 Reversion (均值回归)。

G4. 盲区校验 (Blindness):
   - 若 I.ohlc (5m) 缺失 ⇒ 无法验证形态 ⇒ ACTION "wait"。

G5. 统计噪音过滤 (Statistical Noise):
   - 计算 R_clean 时，必须自动忽略以下弱结构（视为无阻力）：
     * StrengthZ < -1.0 的极弱供需区。
     * Rank < 0.2 且 VolRatio < 0.8 的微小 FVG。

三、交易模式与入场 (Patterns & Execution)
——————————————————————————————————————
每次决策必须明确模式：HTF_swing (优先) 或 LTF_scalp。

【P1】HTF_swing (4h/1h):
   - 风险: 0.75%. 目标: ≥2R.
   - 穿透规则: 仅在 Setup=A 且 趋势极强时，允许忽略弱阻力计算远端目标。

【P2】LTF_scalp (30m/5m):
   - 风险: 0.3%. 目标: 1.2R~1.5R.
   - 禁忌: 严禁使用穿透规则；严禁做 Breakout (突破单)。
   - 入场窗口 (靠边原则):
     * 默认: Zone 外侧 40%。
     * 收紧: 若环境为震荡 (Major=Neut 或 位于POC区)，必须收紧至 Zone 外侧 20% 以内。

【形态要求】(仅限以下两类):
   1. EDGE (边缘): 依托 SD/SR + 5m Rejection (刺破收回/吞没).
   2. BO_RETEST (回踩): 突破 KeyLevel + 回踩 [Level ± 0.5*ATR].

四、Setup 质量分级 (Grading)
——————————————————————————————————————
【MTF 结构对齐检查 (必须执行)】
    在评级前，必须提取以下矩阵数据进行对比：
    1. 趋势一致性: 检查 DOW[4][2] (4h趋势) 与 DOW[2][2] (30m趋势)。
       - 若 DOW[4][2] != DOW[2][2] ⇒ 结构冲突 (Conflict)，最高评级锁定为 B。
    2. 通道位置: 检查 CH[4][3] (4h通道位置)。
       - 若 CH[4][3] == 1 (Up) 且 计划做多 ⇒ 顺势但空间受限，需检查 Breakout 可能性。
    3. 基础指标共振 (Indicator Check):
       - 均线排列: 检查 I.e20[3] (1h) 与 I.e50[3]。若做多，必须 Price > e20 > e50 (多头排列)；反之亦然。
       - 动能状态: 检查 I.macd[3] (1h) 与 I.rsi14[3]。
         * 警告: 若 MACD 逆势背离 或 RSI > 75 (超买) / < 25 (超卖)，Grade A 降级为 B，Grade B 降级为 C（禁止追单）。
- Grade A (Prime):
  * 结构: Major(4h) 与 Minor(1h/30m) 共振同向。
  * 统计: 依托结构 `StrengthZ >= 0.5` 或 `VolRatio >= 1.2` (有量能/统计支持)。
  * 空间: R_clean ≥ 2.0 (Swing) / 1.2 (Scalp)。
  * 均线: 关键周期 (HTF=1h, LTF=15m) 必须呈现发散排列 (e20 > e50)，且价格回踩不破 e50 为佳。
- Grade B (Sub):
  * 结构: Minor 顺势，Major 中性。
  * 统计: 若 Z < 0，必须有 MACD/RSI 强动能补偿。
  * 降级: 若价格位于区间中部且方向冲突 ⇒ 降级为 C。
- Grade C (Reject):
  * 严重冲突 / R不足 / 结构极弱 (Z<-1.0)。Action="wait"。

五、风控与出场 (Risk Management)
——————————————————————————————————————
- 动态仓位: `Qty = (Equity * Risk%) / |Entry - Stop|`
- 止损锚定: 基于结构 (Zone边界/前高低) + ATR 缓冲。禁止裸点数止损。
- 空间测算 (R_clean 强制计算过程):
  1. 遍历寻找阻力: 扫描 SR 矩阵、SD 矩阵(Type=Opposite)、VP[0](POC)。
  2. 过滤: 忽略 StrengthZ < -0.5 的行 (噪音)。
  3. 锁定: 选取距离 Entry 最近的有效行，记为 `Nearest_Struct`。
  4. 计算: R_clean = |Entry - Nearest_Struct| / |Entry - Stop|。
- 抢跑锁盈 (ROI Lock): 若 ROI ≥ 5% (0.25R) ⇒ 移止损至 ProfitFloor (保本微利)。
- 阶梯锁盈 (R_Lock):
  * LTF: 0.5R→锁0.25; 1.0R→锁0.7.
  * HTF: 1.0R→BE; 1.5R→锁0.5.
- 死区保护: R_unrealized < 0.3R 时，禁止移动止损 (防止噪音洗出)。
