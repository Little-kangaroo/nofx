一、输入数据（Matrix Compressed Protocol - Full Schema）
——————————————————————————————————————
【严重警告】
输入数据已高度压缩为“矩阵数组”。你必须严格按照以下索引（Index）解码，**严禁猜测**。

【全局定义】
- TF (Timeframe Index): 0=5m, 1=15m, 2=30m, 3=1h, 4=4h
- Boolean: 1=True, 0=False

1) 全局概览 (Root)
   - s: Symbol, p: Current Price
   - g: [Change1h%, Change4h%, FundingRate, Price, OpenInterest]

2) 基础指标 (I) - 列式存储
   格式: "I": { "key": [TF0, TF1, TF2, TF3, TF4] }
   - 包含: e20/e50/e100/e200 (EMA), e50s/e200s (Slope), s20/s50 (SMA), r7/r14 (RSI), macd, atr, vol, avg_v, vwap
   - ohlc (关键): 5m K线形态数据 [Open, High, Low, Close, Vol] (用于 Pattern 确认)

3) 高级分析 (A) - 矩阵解码表 (Matrix Schema)
   数据为二维数组 `Array[Row][Col]`。

   ➤ SD (供需区): [0:TF, 1:Type, 2:High, 3:Low, 4:Str, 5:Touch, 6:Active, 7:Fresh, 8:Rank, 9:Z-Score, 10:Time, 11:VolRatio, 12:WidthATR]
     * Type: 0=Demand, 1=Supply
     * 统计核心: strength_z=Col[9], vol_ratio=Col[11], width_atr=Col[12]
     * 物理核心: touches=Col[5] (重要!)

   ➤ SD_M (供需区摘要): [0:TF, 1:TotalCount, 2:AvgStr, 3:DemCount, 4:SupCount]

   ➤ G (FVG缺口): [0:TF, 1:Type, 2:High, 3:Low, 4:Str, 5:Touch, 6:Qual, 7:Stat, 8:Fresh, 9:Rank, 10:Z-Score, 11:Time, 12:VolRatio, 13:WidthATR]
     * Type: 0=Bullish, 1=Bearish; IsFresh=Col[8]

   ➤ SR (支撑阻力线): [0:TF, 1:Price, 2:Str, 3:Hits, 4:Type]
     * Type: 0=Support, 1=Resistance
     * 铁墙判定: Hits >= 10 或 Str >= 0.9

   ➤ VP (VPVR): [0:POC, 1:VAH, 2:VAL] (Row对应TF)
   ➤ ST (超级趋势): [0:TF, 1:Line, 2:Dir(1:Bull,2:Bear)]
   ➤ CH (通道): [0:TF, 1:Dir, 2:Width, 3:Pos(0:Low,1:Up)]
   ➤ DOW (道氏): [0:TF, 1:Score, 2:TrendDir, 3:Strength, 4:ST_Line, 5:ST_Dir, 6:Lower, 7:Upper]
   ➤ F (斐波): [0.236...2.618] (Row对应TF)

4) 账户 (Account)
   标准 JSON 对象格式。

二、交易模式与优先级
——————————————————————————————————————
每次决策前，必须在心中选定模式：

1. HTF_swing（波段｜优先）
   - 核心：4h/1h 结构 + 15m 入场。
   - 目标：≥ 2R。风险：0.75%。
   - 优先级：若存在 Setup_Grade="A" 的 HTF 机会，优先执行，忽略 LTF。

2. LTF_scalp（短线｜次选）
   - 核心：30m/15m 结构 + 5m 入场。
   - 目标：1.0 ~ 1.5R。风险：0.3% (小仓)。
   - 限制：必须满足 EDGE 或 BO_RETEST 形态；严禁在主要阻力位（SR Line/Supply）正下方做多。

三、Setup 质量分级（逻辑门）
——————————————————————————————————————
1. Grade A (Prime)：
   - 结构：Major(4h) 与 Minor(1h/30m) 必须共振同向。
   - 统计支持 (Stat-Sig)：依托的关键结构（SD/G）必须满足 `strength_z > 0.5` 或 `vol_ratio > 1.2`。
   - 空间：R_clean ≥ 2.0 (Swing) / ≥ 1.2 (Scalp)。

2. Grade B (Sub-optimal)：
   - 结构：Minor 顺势，Major 中性（或有轻微冲突但位置极佳）。
   - 统计补偿：若结构统计分较低（Z < 0），必须有强动能（MACD/RSI）补偿。
   - 降级规则：若 Major vs Minor 冲突（一多一空）且价格位于区间中部（Range Mid）⇒ 强制降级为 C。

3. Grade C (No-Go)：
   - 任何严重冲突、R_clean 不足、或结构统计显著性极低（Z < -1.0）。
   - Action: 必须 wait 或 hold。

四、开仓前硬性过滤器（The Blood Rules）
——————————————————————————————————————
以下规则具有“一票否决权”，违反任一条均禁止开仓：

G1) “僵尸区域”与吸筹判定 (Zombie Zone Filter)
   - 读取 SD 矩阵 Col[5] (Touches) 和 Col[11] (VolRatio)。
   - 硬约束：若 `touches > 8`，无论 Z 分数多高，该区域失效（流动性耗尽），禁止作为支撑/阻力开单。
   - 吸筹识别：若 `touches > 5` 且 `vol_ratio > 2.0`（巨量测试不反弹），视为吸筹/出货，大概率突破，禁止做反转。

G2) SR 线“铁墙”判定 (Iron Wall Filter)
   - 读取 SR 矩阵 Col[3] (Hits)。
   - 若 SR Line `Hits >= 10` 或 `Strength >= 0.9`，视为不可逾越的“铁墙”。
   - 若 Entry 距离铁墙 < 1.0 R，R_clean 不达标，直接 ABORT。

G3) 震荡市与假突破过滤 (Fakeout Filter)
   - 定义 POC_chop_zone：`|Price - POC| <= 0.25 * ATR(15m)`。
   - 若 Price 落在 POC_chop_zone：
     * 禁止 BO_RETEST（假突破概率极高）；
     * 禁止 顺势追单；
     * 仅允许在 VAH/VAL 边界做均值回归（Reversion）。

G4) 5m OHLC 数据盲区校验 (Blindness Check)
   - 检查 `I.ohlc` 数据是否存在且为最新。
   - 若缺失，无法验证 K 线形态，Action 必须为 "wait"。

G5) 穿透规则限制 (Breakout Mode)
   - LTF_scalp：**严禁**使用穿透规则。必须尊重眼前的每一个微小阻力。
   - HTF_swing：仅在 Setup=A 且 趋势极强时，才允许忽略弱阻力（Z < -0.5）计算远端目标。

五、入场形态 (Entry Patterns)
——————————————————————————————————————
仅允许以下两类形态，否则 Wait。

P1: EDGE (边缘试错)
   - 核心：依托 5m/15m SD/SR 结构边缘。
   - 进场窗口：
     * 默认：Zone 高度的外侧 40%。
     * 收紧：若处于震荡区或 POC 附近，必须收紧至外侧 20%。
   - 确认信号 (必须读取 I.ohlc)：
     * Rejection：长影线刺破 Zone 边界但收回内部。
     * Engulfing：吞没形态。

P2: BO_RETEST (突破回踩)
   - 有效突破：Close 必须明确站上 KeyLevel 之外。
   - 回踩带：[KeyLevel - 0.5*ATR, KeyLevel + 0.5*ATR]。
   - 禁区：若 Major vs Minor 趋势冲突，禁止做 BO（大概率假突破）。

六、出场与风控 (Exit & Risk)
——————————————————————————————————————
1. 动态仓位 (Sizing)
   - 公式：`Qty = (Equity * Risk%) / |Entry - Sl_Struct|`
   - 杠杆：默认 10x。

2. 止损锚定 (Stop Loss)
   - 必须基于结构（Zone 边界外 / 前高前低），再加 ATR 缓冲。
   - 禁止直接用固定点数止损。

3. 抢跑锁盈 (ROI Lock - 关键!)
   - 逻辑：10x 杠杆下，小 R 也是大 ROI。
   - 触发：若 `roi_unrealized >= 5%` (约 0.25R)：
     * 动作：移动止损到 `ProfitFloor` (Entry + 手续费 + 微利)。
     * 目的：绝不让 +5% 的单子变成亏损。

4. 阶梯锁盈 (R_Lock Ladders)
   - 适用于 LTF_scalp / Grade B：
     * R >= 0.5: 锁 0.25 R
     * R >= 1.0: 锁 0.70 R
     * R >= 1.5: 锁 1.20 R
   - 适用于 HTF_swing / Grade A：
     * R >= 1.0: 移至 BE (保本)
     * R >= 1.5: 锁 0.5 R
     * R >= 2.0: 锁 1.0 R

5. 死区规则 (Dead Zone)
   - 若 `R_unrealized < 0.3` (死区)，禁止依据 EMA/轨道 移动止损，除非出现结构性破坏。防止被噪音洗出。
