# AI自动交易系统 - 技术指标计算文件映射表

## 项目概述
本文档详细记录了AI自动交易系统中所有技术指标的计算实现位置和对应关系。
系统采用Go语言开发，支持加密货币市场的实时技术分析和AI交易决策。

## 基础技术指标 (/market/data.go)

### ATR (平均真实范围)
- 函数: calculateATR()
- 功能: 计算指定周期的平均真实范围
- 支持: 多周期计算 (ATR3, ATR14等)
- 算法: Wilder平滑方法

### EMA (指数移动平均)  
- 函数: calculateEMA()
- 支持周期: EMA20, EMA50, EMA100, EMA200
- 特色: 包含收敛建议和精度警告
- 斜率计算: calculateEMASlope() - 3根K线回看期

### SMA (简单移动平均)
- 函数: calculateSMA()  
- 功能: 各时间框架基础均线计算
- 用途: 与EMA配合进行趋势分析

### MACD
- 函数: calculateMACD()
- 算法: 基于EMA12和EMA26的差值
- 输出: MACD值，用于动量分析

### RSI (相对强弱指标)
- 函数: calculateRSI()
- 支持周期: RSI7, RSI14  
- 算法: 使用Wilder平滑方法
- 稳定性: 建议使用周期3倍数据量

### VWAP (成交量加权均价)
- 函数: calculateVWAP()
- 算法: 典型价格×成交量加权
- 用途: 判断价格相对公允价值位置

### SuperTrend (超级趋势)
- 函数: calculateSupertrendEnhanced()
- 特色: 增强版实现，支持动态参数配置
- 功能: 趋势方向、强度量化、信号质量评估
- 优化: 智能初始化、减少假信号

## 高级结构分析指标

### FVG (公允价值缺口) (/market/fvg.go)
- 核心结构: FVGAnalyzer
- 主要方法: Analyze() 
- 功能: 
  * 识别看涨/看跌缺口
  * 缺口强度评估  
  * 触及次数统计
  * 缺口填补检测

### VPVR (成交量分布) (/market/vpvr.go)
- 核心结构: VPVRAnalyzer
- 关键方法:
  * calculatePriceLevels() - 价格区间划分
  * findPOC() - 寻找成交量控制点 
  * calculateValueArea() - 计算价值区域
- 特色: Z-Score标准化支持

### 供需区分析 (/market/supply_demand.go)  
- 核心结构: SupplyDemandAnalyzer
- 主要方法: AnalyzeWithSymbol()
- 功能:
  * Z-Score标准化
  * 区域强度评分
  * 触及统计
  * 动态区域更新

### 斐波纳契分析 (/market/fibonacci.go)
- 核心结构: FibonacciAnalyzer  
- 支持分析类型:

### 支撑阻力转换线 (/market/support_resistance.go)

## 系统集成点 (/market/data.go)

### 主入口函数
- Get() 函数: 统一数据获取接口
- 功能: 协调所有指标计算和数据整合

### 格式化输出  
- FormatAsCompactData(): AI交易员专用精简格式
- getOrderFlowDataForAI(): 订单流数据集成

- 精度控制: FormatByDataTypeAndSymbol()按币种适配精度

### 精度格式化

## 技术指标输出数据结构映射

### 用户数据结构中的指标对应关系:
```
基础指标 -> /market/data.go 中的计算函数
├── current_price -> 最后已收盘K线价格
├── current_ema20 -> calculateEMA(klines, 20)
├── current_macd -> calculateMACD(klines)  
├── current_rsi7 -> calculateRSI(klines, 7)
├── price_change_1h -> 基于5分钟K线回看计算
├── price_change_4h -> 基于4小时K线计算
├── atr14 -> calculateATR(klines, 14)
├── vwap -> calculateVWAP(klines)
└── supertrend -> calculateSupertrendEnhanced()

多时间框架分析 -> /market/comprehensive_analysis.go
├── 5m级别 -> ComprehensiveAnalyzer.AnalyzeMultiTimeframe()
├── 15m级别 -> 各分析器针对15分钟数据
├── 30m级别 -> 各分析器针对30分钟数据  
├── 1h级别 -> 各分析器针对1小时数据
└── 4h级别 -> 各分析器针对4小时数据

订单流分析 -> /microstructure/ 包
├── CVD数据 -> cvd_calculator.go
├── OI数据 -> open_interest.go  
├── 盘口数据 -> orderbook_analyzer.go
└── 数据质量 -> 综合评估机制
```
